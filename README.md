# 🪨 Rock, Paper, Scissors ✂️

A simple and fun **Rock, Paper, Scissors** game built with HTML, CSS, and JavaScript!  
Play against the computer and see who wins.
Live Demo: https://rock-paper-scissors-pi-sable.vercel.app/
---

## 🎮 Features

- Choose between **Rock**, **Paper**, or **Scissors**
- The computer makes a random choice each round
- **Win**, **Lose**, or **Draw** results displayed instantly
- Scoreboard that keeps track of points
- **Reset button** to start a new game
- **Light bulb toggle** 💡 — switch between dark and light background for a custom look
